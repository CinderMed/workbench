description: Worked examples of mapping real datasets to FHIR.
---

Two worked examples will guide you through a complete mapping:

- **Metastra**: import a data dictionary, create the resource roles, fill in value maps and export the FML package.
- **MOTU**: several linked tables, with references between resources.

Each example is a project file in the repository, checked on every change, so what you read here always works.
