Named slices (D4, #39) in the local mode: on a repeating element such as `component`, the path picker names a repetition (`component[nrs]`) with a fixed value that tells it apart (a code, entered as `manual`, or a simple value), saves it in the role and shows it under its element for the rows to write to; the role editor lists each role's slices and deletes one after saying how many rows write to it.
