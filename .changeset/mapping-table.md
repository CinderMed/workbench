`mappingTables`, `toCsv` and `toXlsx` write the mapping table (H1): Mapping, Value maps (every map, boolean ones included, with actions and code verification), Roles and Columns, as CSV (BOM, CRLF, configurable delimiter, formula-injection escape) or as a deterministic XLSX workbook. `@cindermed/fml` exports `conditionText` and `roleCondition`.
