Filters and bulk actions (D8, #41) in the local mode: filters by review status, role and section; rows selected with Space, Ctrl or Cmd-click, Shift-click or "Select all shown"; a role or a review status set on all selected rows in one change. The role editor keeps the Index field empty while it is cleared, so a typed index replaces the proposed one, and refuses an empty index.
