# @cindermed/fml

The FHIR Mapping Language side of CinderMed: the FML syntax tree and printer, the generator that turns a mapping project into FML, StructureMap JSON, logical models and normalization specifications, and the grammar check.

Part of [CinderMed](https://github.com/CinderMed/workbench), a workbench to map tabular datasets to FHIR and generate FML. Not published to npm yet: the packages are built and used from the repository.
