# @cindermed/fhir-defs

FHIR R4 and R5 definitions for CinderMed: the compact definition index, element trees, path resolution and the FHIR checks of a mapping project (paths, types, bindings, references, cardinality).

Part of [CinderMed](https://github.com/CinderMed/workbench), a workbench to map tabular datasets to FHIR and generate FML. Not published to npm yet: the packages are built and used from the repository.
