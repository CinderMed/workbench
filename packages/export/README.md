# @cindermed/export

The export package of CinderMed: the deterministic zip with the maps, logical models, normalization specifications, ConceptMaps and manifest of a mapping project, and the mapping table (CSV, XLSX).

Part of [CinderMed](https://github.com/CinderMed/workbench), a workbench to map tabular datasets to FHIR and generate FML. Not published to npm yet: the packages are built and used from the repository.
